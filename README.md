# Hospital-Management-System-v1
 - This is a Flask SQLAlchemy Web Application that manages working process and Administration of Hospitals.
 - It has role-based functionality for three kinds of user: Admin, Doctor and Patient
 - Some of the Tasks performed are:
    - Appointment booking by patient
    - Adding Treatment and Diagnosis report by doctors
    - Scheduling appointments, Monitoring doctor schedule, Maintaining patient treatment record by Admin
